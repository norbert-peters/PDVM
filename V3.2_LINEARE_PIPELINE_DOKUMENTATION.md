# V3.2 Lineare Pipeline - Dokumentation

## 🎯 Problemstellung

**V3.1 Fehler**:
- Welcome-Widget wurde in STEP 3.1 gelöscht
- Handler rufen `_show_welcome_message()` auf → verwenden gelöschtes Widget
- Fehler: `RuntimeError: wrapped C/C++ object of type QTextEdit has been deleted`

**User-Anforderung**:
> "Es muss vom Ablauf her bei allen gleich laufen:
> 1. Handler wird aufgerufen
> 2. Handler bereitet seine Parameter für die Pipeline auf
> 3. Pipeline arbeitet linear..."

## ✅ Lösung: V3.2 Lineare Pipeline

### Ablauf-Logik (STRIKT LINEAR)

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Handler wird aufgerufen                                  │
│    → Bereitet Parameter für Pipeline auf                    │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ 2. Pipeline arbeitet (workspace_pipeline)                   │
└─────────────────────────────────────────────────────────────┘
                           ↓
              ┌────────────┴────────────┐
              │                         │
         skip_clear=FALSE         skip_clear=TRUE
         (Neu belegen)            (Behalten)
              │                         │
              ↓                         ↓
┌─────────────────────────┐   ┌─────────────────────────┐
│ STEP 3.1:               │   │ STEP 4.1:               │
│ Workspace LEEREN        │   │ Workspace BEHALTEN      │
└────────────┬────────────┘   └────────────┬────────────┘
             ↓                             ↓
┌─────────────────────────┐   ┌─────────────────────────┐
│ STEP 3.2:               │   │ STEP 4.2:               │
│ command_func() ausführen│   │ command_func() ausführen│
│ (Handler-Logik)         │   │ (Handler-Logik)         │
└────────────┬────────────┘   └────────────┬────────────┘
             ↓                             ↓
┌─────────────────────────┐   ┌─────────────────────────┐
│ STEP 3.3:               │   │ STEP 4.3:               │
│ Workspace leer?         │   │ alternativ_skip_clear?  │
│ → JA: Welcome-Screen    │   │                         │
│   einfügen              │   │ FALSE → Pipeline Ende   │
│ → NEIN: Fertig          │   │ TRUE  → STEP 4.4        │
└─────────────────────────┘   └────────────┬────────────┘
                                            ↓
                              ┌─────────────────────────┐
                              │ STEP 4.4:               │
                              │ Workspace LEEREN        │
                              └────────────┬────────────┘
                                            ↓
                              ┌─────────────────────────┐
                              │ STEP 4.5:               │
                              │ alternativ_func()       │
                              │ oder Welcome-Screen     │
                              └─────────────────────────┘
```

### Pipeline-Signatur

```python
def workspace_pipeline(
    self, 
    command_func=None,           # Haupt-Handler-Funktion
    error_message=None,          # Fehlermeldung (optional)
    skip_clear=False,            # False = Workspace leeren, True = behalten
    alternativ_skip_clear=False, # True = Nach skip_clear Workspace löschen
    alternativ_func=None         # Funktion für leeren Workspace
) -> bool:
```

### Parameter-Matrix

| Szenario | skip_clear | alternativ_skip_clear | alternativ_func | Ergebnis |
|----------|-----------|----------------------|----------------|----------|
| **View öffnen** | False | - | - | Workspace gelöscht → View → Fertig |
| **Startmenü** | False | - | - | Workspace gelöscht → Menü geladen → Welcome eingefügt |
| **App-Menü** | False | - | - | Workspace gelöscht → Menü geladen → Welcome + App-Name |
| **Menü Toggle** | True | False | - | Workspace bleibt → Menü toggled → Fertig |
| **Stichtagsbar Toggle** | True | False | - | Workspace bleibt → Stichtagsbar toggled → Fertig |
| **UI Reset** | True | True | custom_func | Workspace bleibt → Aktion → Workspace gelöscht → custom_func |

## 🔧 Implementierung

### 1. Pipeline-Code (v2_systemstart.py)

```python
def workspace_pipeline(self, command_func=None, error_message=None, 
                      skip_clear=False, alternativ_skip_clear=False, 
                      alternativ_func=None):
    """V3.2: LINEARE PIPELINE nach User-Vorgabe"""
    
    # STEP 3.1 / 4.1: Workspace leeren (bedingt)
    if not skip_clear:
        logger.info("🧹 STEP 3.1: Workspace-Frame leeren...")
        self._clear_workspace_layout()
    else:
        logger.info("⏭️ STEP 4.1: Workspace bleibt unverändert")
    
    # STEP 3.2 / 4.2: Hauptaufruf ausführen
    if command_func:
        result = command_func()
    else:
        result = True
    
    # STEP 4.3-4.5: Alternativ-Logik (nur bei skip_clear=True)
    if skip_clear:
        if alternativ_skip_clear:
            self._clear_workspace_layout()
            if alternativ_func:
                alternativ_func()
            elif self.workspace_layout.count() == 0:
                self._insert_welcome_screen()
        return result
    
    # STEP 3.3: Workspace-Füllung garantieren
    if self.workspace_layout.count() == 0:
        if alternativ_func:
            alternativ_func()
        else:
            self._insert_welcome_screen()
    
    return result
```

### 2. Helper-Methoden

```python
def _clear_workspace_layout(self):
    """Löscht ALLE Widgets aus workspace_layout"""
    while self.workspace_layout.count() > 0:
        item = self.workspace_layout.takeAt(0)
        if item.widget():
            widget = item.widget()
            widget.hide()
            widget.deleteLater()

def _insert_welcome_screen(self):
    """
    Fügt Welcome-Screen in workspace_layout ein
    WICHTIG: Erstellt NEUES Widget (altes wurde gelöscht!)
    """
    # Erstelle NEUES Widget
    self.welcome_widget = self._create_welcome_widget()
    self._show_welcome_message()
    
    # Füge in Workspace ein
    self.workspace_layout.addWidget(self.welcome_widget)
    self.welcome_widget.show()
    
    # App-Name einfügen (falls gesetzt)
    if hasattr(self, '_current_app_name') and self._current_app_name:
        # ... HTML-Anpassung ...
        self._current_app_name = None  # Reset
```

### 3. Handler-Pattern (V3.2)

**WICHTIG**: Handler dürfen NICHT mehr `_show_welcome_message()` aufrufen!

```python
# handlers/handler_open_start_menu.py
SKIP_CLEAR = False  # Workspace leeren, Pipeline fügt Welcome ein

def execute(params: dict, context: dict, gcs) -> bool:
    """
    V3.2: Lineare Pipeline-Logik
    STEP 3.1: Workspace wird geleert (skip_clear=False)
    STEP 3.2: Handler lädt Menü (KEIN Widget einfügen!)
    STEP 3.3: Pipeline prüft Workspace leer → fügt Welcome-Screen ein
    """
    menu_handler = context.get('menu_handler')
    
    # Lade Startmenü (KEIN _show_welcome_message()!)
    success = menu_handler.load_startmenu()
    if success:
        logger.info("✅ Startmenü geladen")
        # Pipeline fügt Welcome-Screen automatisch ein (STEP 3.3)
        return True
    
    return False
```

## 🎯 Gewinn durch V3.2

1. ✅ **Keine gelöschten Widgets**: Welcome-Widget wird neu erstellt statt wiederverwendet
2. ✅ **Klare Verantwortung**: Handler laden Menüs, Pipeline verwaltet Workspace
3. ✅ **Linear & Vorhersehbar**: Fester Ablauf ohne Sonderfälle
4. ✅ **Erweiterbar**: `alternativ_skip_clear` + `alternativ_func` für komplexe Szenarien
